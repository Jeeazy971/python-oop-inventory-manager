# Python OOP Inventory Manager

Projet d’apprentissage dédié à la **programmation orientée objet en Python**.

Ce repository fait partie d’un parcours progressif pour construire des bases solides en Python, avec un focus sur :

- les classes ;
- les objets ;
- `__init__` ;
- `self` ;
- les attributs ;
- les méthodes ;
- l’encapsulation ;
- la composition ;
- les propriétés ;
- les dataclasses ;
- l’héritage simple ;
- le polymorphisme simple ;
- l’organisation d’un mini-projet orienté objet.

---

## Objectif du projet

Construire progressivement un mini gestionnaire d’inventaire.

Le projet permettra de représenter des produits, gérer un stock, ajouter ou retirer des quantités, calculer des valeurs, et organiser le code avec une structure propre.
